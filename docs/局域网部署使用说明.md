# BackupMonitor 局域网部署使用说明

版本：2026-08-13

本系统的普通使用流程只需要两个 EXE：

- `BackupMonitor.Server.Setup.exe`：放到局域网服务器上，双击安装服务端。
- `BackupMonitor.Agent.Setup.exe`：从服务端网页下载，复制到需要纳管的 Windows 电脑上，双击安装客户端。

普通用户不需要安装 .NET、Node.js、PostgreSQL、Git 或 PowerShell 模块，也不需要运行脚本、填写数据库连接串、复制注册令牌或接触开发密钥。

## 一、安装服务端

1. 将 `BackupMonitor.Server.Setup.exe` 复制到准备作为 BackupMonitor Server 的 Windows Server 或 Windows 11 电脑。
2. 双击文件并允许管理员权限。
3. 输入管理员网页登录密码。密码至少 12 个字符，请妥善保存；安装程序不会使用固定默认密码。
4. 保持安装目录、数据目录和端口的默认值，点击“安装”。
5. 安装程序会自动完成专用 PostgreSQL 实例、数据库迁移、内部密钥、局域网自签 HTTPS 证书、Windows 服务、防火墙规则和首次初始化，并在完成后打开管理网页。
6. 使用安装时设置的密码登录管理网页。首次登录如果提示修改密码，请按页面要求完成修改。

服务端 PostgreSQL 是 BackupMonitor 专用实例，只监听服务器本机，不会修改电脑上已有的 PostgreSQL 实例。局域网访问只允许 Windows“专用网络”配置文件中的规则。

## 二、安装客户端

1. 在管理网页打开“客户端”页面，点击“下载客户端安装程序”。
2. 首次从 LAN Turnkey 服务端安装 Agent 前，在客户端电脑导入服务端返回的“服务端根证书 PEM”。应将该公开证书导入“本地计算机\受信任的根证书颁发机构”；不要导入任何 PFX、私钥或 `server-secrets.json`。
3. 将下载的 `BackupMonitor.Agent.Setup.exe` 复制到需要纳管的新电脑。
4. 双击安装器。安装器会自动扫描局域网中的 BackupMonitor Server。
5. 只发现一台服务器时会自动选中；发现多台时选择正确的服务器；扫描不到时才在地址框中填写管理网页地址。LAN Turnkey 地址必须使用 `https://`。
6. 点击“安装 Agent”。安装器会读取并固定服务端证书指纹；客户端服务和托盘会自动安装、启动并登记到服务端，成功后会在“客户端”页面显示为在线。

LAN 自动登记不需要一次性注册令牌，也不需要管理员逐台审批。只有运维人员明确使用 Secure 高级部署模式时，才需要在“高级选项”中使用原有的令牌流程。

## 三、日常使用

### 建一个备份任务

在“备份任务”页面新建任务，只有四件事需要决定：

1. **备份哪台机器上的什么** —— 选客户端，填源路径（客户端本机的目录）和识别器类型；必要时填“必需文件”，缺文件就判为备份不完整。
2. **什么时候备份** —— 高级选项里的“扫描计划”（cron）。需要错开多台机器时再设“上传窗口”和“随机延迟”。
3. **存几份** —— 高级选项里绑定一个“保留策略”（在“保留策略”页面维护：保留最近 N 个版本、最短保留天数、回收区天数）。不绑定就一直留着。
4. **存到哪** —— 这是服务端全局设置，不在任务里，见下一节。

任务模式默认是“自动”：客户端扫到新备份、预检通过后立即上传入库，不需要任何人工确认。只想先观察不上传时才改成“仅监控”。

### 备份存放在哪里

在“存储设置”页面查看和修改两个目录：

- **备份存放目录**：校验通过的备份最终存这里，按 `主机名\任务名\备份时间` 分层，每份备份附一个 `manifest.json` 文件清单（含每个文件的 SHA-256，恢复时按它校验）。
- **上传暂存目录**：上传过程中的临时分块，提交后自动清理。建议与上一项放在不同磁盘。

页面上会显示当前实际生效的路径、所在磁盘剩余空间和目录是否可写。保存前会实地建目录并试写一个文件，写不进去会当场报错。

改路径后，新备份写入新目录，**已入库的备份仍留在原目录，不会被移动也不会丢失**，仍可查看和恢复；但保留策略到期时无法自动删除它们的文件，需要人工把老目录搬到新目录下或手动清理。页面在这种情况下会给出提示和数量。

- 在“客户端”页面查看电脑在线状态、CPU、内存、磁盘、网络、登录会话、Windows 服务和历史趋势。
- 托盘只显示需要关注的异常报警和备份完成消息；退出托盘不会停止 Agent 服务。
- Agent 服务由 Windows 服务控制管理器托管，异常退出时会自动重启。

## 四、维护与卸载

### 服务端

再次运行 `BackupMonitor.Server.Setup.exe` 会进入维护模式，可以执行修复/升级、重启服务、重新签发服务端证书、打开管理网页、查看诊断信息、重置管理员密码或卸载。

重新签发服务端证书会改变证书指纹；重新签发后需要在每台 Agent 上重新运行客户端安装器，让客户端更新固定指纹。证书吊销仍由服务端按客户端证书指纹即时检查，不依赖 CRL/OCSP。

忘记网页登录密码时，在维护模式选择“重置管理员密码”，设置新密码后再登录；该操作会吊销旧的刷新会话。

卸载服务端时默认保留数据库、客户端身份、CA 和历史数据。只有明确确认删除数据时，安装器才会移除这些数据。

### 客户端

再次运行 `BackupMonitor.Agent.Setup.exe` 会显示“修复/重新安装”和“卸载 Agent”。卸载会停止并删除 Agent 服务、托盘自启动和客户端安装文件；可以选择是否同时删除客户端运行数据和本地证书。

## 五、常见情况

- 安装器没有发现服务器：确认两台电脑在同一局域网、网络配置文件为“专用网络”，并确认服务器网页可访问。也可以在安装器中填写服务端地址后重试。
- 发现多台服务器：在列表中选择实际使用的那一台，不要依靠机器名称猜测。
- 服务端网页暂时打不开：在服务端运行安装器维护模式中的“诊断”和“重启服务”，查看服务状态和数据库状态。
- 客户端没有上线：确认客户端安装完成后 Agent 服务正在运行，并检查服务端“客户端”页面；不要复制注册令牌或修改数据库文件。
